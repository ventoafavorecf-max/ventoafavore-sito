问题所在

问题不在措辞时，就在页面本身

这样的情形并不少见：一家企业业务扎实，但意大利语页面要么出自翻译软件，要么已经八年没有更新，要么干脆没有意大利语页面。

意大利的买家上网查找您时，无论如何都会看到这个页面，而在那一刻，它就是买家对您的全部了解。

因此，Vento a Favore 有两种工作方式：把您现有的页面改写成意大利语，交付可直接上传的成品；或者在没有任何基础的情况下，从零开始建设意大利语网站。

您将获得什么

是页面，而不是一套系统

无论是您现有的页面，还是全新的网站，都遵循以下四条原则。

  1. 01

    无需维护

    没有管理后台，没有密码，也没有某天早晨突然失效的插件。页面保持交付时的样子，直到您提出要求，由 Vento a Favore 进行修改。

  2. 02

    先给数据，再讲故事

    信息按买家做决定所需的顺序排列：标准、尺寸、交货期、谁来接电话。企业历史随后出现，在它该发挥作用的位置。

  3. 03

    域名始终属于您

    域名注册在您的名下。Vento a Favore 先行垫付，再按实际成本收取，不加价。托管服务免费，同样登记在您的名下。

  4. 04

    速度快，并且一直保持

    不需要下载任何程序库，也没有任何追踪读者的内容：页面轻巧，即使在工厂车间的网络环境下也能快速打开。

流程

四个步骤，没有意外

价格就是价目表上的价格，在您联系之前就已知晓。计时从第三步开始，而不是第一步。

  1. 开始

    提出需求

    发一封邮件即可：如有现有网站，请附上网址；如没有，请用两句话说明您生产什么。无需填写必填表格。

  2. 一天之内

    报价方案

    需要几个页面、每个页面包含什么、价目表上的价格，以及所需工作日天数。

  3. 随后

    提供资料

    您已有的文字、照片（如有）以及产品数据。天数从这里开始计算。如果没有可用的照片，会提前告知：网站将以文字、数据和图纸为基础来构建。

  4. 交付时

    交付

    网站上线，域名登记在您名下，三十天内可进行一轮修改。
